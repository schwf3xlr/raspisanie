# Скриншоты для RuStore

Минимум **3**, оптимально **5-6**. Формат: PNG, вертикальные, 1080×2400 (или другой 9:19-9:21).

## Список экранов

| № | Экран | Как открыть | Что показать |
|---|---|---|---|
| 1 | **Расписание на день** (главный) | `/app` → выбрать класс → любой рабочий день | Крупный «Четверг», список уроков, метка «Сейчас», прогресс-бар до звонка |
| 2 | **Общая таблица школы** | `/all` | Все классы сеткой, желательно с одним дистантным классом (серая колонка) — покажет фичу |
| 3 | **Учительский режим** | На странице выбора нажать «Я учитель», выбрать любого | Расписание учителя с классами вместо предметов справа |
| 4 | **Выбор класса** | `/app` в новой инкогнито-вкладке | Красивая сетка карточек 5А, 5Б, 6А, ... с заголовками параллелей |
| 5 | **Настройки** | На главной нажать шестерёнку сверху справа | Открытый bottom-sheet с темой, обновлением, раскрытым блоком «Уведомления» |
| 6 | **Тёмная тема** | Настройки → Тема → Тёмная → главный экран | То же расписание, тёмная |

## Как снять (без телефона — прямо из Chrome)

1. Открой https://school.rskbot.ru в Chrome.
2. `F12` → **Toggle device toolbar** (`Ctrl+Shift+M`).
3. Сверху — выпадающее меню размеров → выбери «Pixel 7» (1080×2400 будет автоматически подставлено).
4. Если хочется тёмную тему — правый нижний угол DevTools → `⋮` → **More tools** → **Rendering** → в самом низу **Emulate CSS media feature `prefers-color-scheme`: dark**.
5. Наверху карусели устройств — `⋮` → **Capture screenshot**. PNG сохранится сам.

## Как снять (с телефона)

- Открой приложение / браузер с приложением, нажми системный скриншот (обычно **громкость-вниз + питание**).
- Скинь с телефона в облако / по кабелю.

## Совет по порядку

RuStore показывает скриншоты в том порядке, в каком ты их загрузишь. Первый и второй — самые важные, их видят на карточке в списке до открытия. Ставь:

1. Главный экран расписания в светлой теме (это же продажа приложения).
2. Общая таблица школы (вау-фича).
3-6. Остальные.
