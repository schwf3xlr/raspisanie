# Синхронизация с Google Таблицами

Приложение умеет читать расписание из Google Sheets и записывать в них. Раздельно для **стандартного расписания** (шаблона по дням недели) и **расписания на неделю** (замены/дистант на конкретные даты).

## 1. Формат таблицы

В одной таблице **5 листов** с точными названиями:

- `Понедельник`
- `Вторник`
- `Среда`
- `Четверг`
- `Пятница`

На каждом листе одинаковая структура:

| Ячейки | Что | Пример |
|---|---|---|
| `B8`–`B15` | Время уроков (8 строк) в формате `HH:MM - HH:MM` | `8:10 - 8:50` |
| `C7`–`S7` | Имена классов | `5А`, `10А`, `11Б` |
| `C8`–`S15` | Предметы уроков | `Математика` |

**Ячейка урока** — это предмет для указанного класса на указанный номер урока. Например, ячейка `E10` на листе «Понедельник» — это 3-й урок класса, чья шапка стоит в `E7`.

**Пометка «дист.»** в имени класса означает, что весь день у класса дистанционный: `5А ДИСТ.`, `5А Д.О.`, `5А д/о` — всё распознаётся. При импорте расписания на неделю (не шаблона) это создаёт `DistantMark` на весь день.

Пустая ячейка урока = урока нет. При импорте расписания на неделю пустая ячейка на месте, где в шаблоне был урок, создаёт «отмену» урока.

## 2. Что синхронизируется

**Стандартное расписание** (`kind = template`):
- Читаются/пишутся все 5 листов (все дни недели).
- Обновляется таблица `LessonTemplate` и `TimeSlot` (звонки).
- Пометка «дист.» игнорируется — это override-состояние, шаблон её не хранит.
- **Перезаписывает** существующие уроки этого дня × класса.

**Расписание на неделю** (`kind = schedule`):
- Импортер применяет к 5 рабочим дням указанной недели.
- Уроки → `LessonOverride`.
- Пустая ячейка на месте, где в шаблоне был урок, → override с `isCancelled = true`.
- «Дист.» в имени класса → `DistantMark` на весь день.
- Звонки, отличные от стандартных, → override-время у уроков.

## 3. Направление

При создании привязки выбирается:
- **Только импорт** — читаем из Google, применяем к БД. Ручное действие в панели.
- **Только экспорт** — читаем из БД, пишем в Google.
- **В обе стороны** — обе кнопки доступны, каждое действие — ручное.

Автоматической синхронизации нет — только по нажатию кнопки в панели. Это защита от случайной перезаписи.

## 4. Что делать

### 4.1 Один раз: сервисный аккаунт

Google Sheets API требует сервисный аккаунт. Мы уже используем сервисный аккаунт Firebase для FCM — можно **тот же самый**, если добавить ему доступ к таблице.

Если хочется отдельный сервисный аккаунт для Sheets:

1. Открой [Google Cloud Console](https://console.cloud.google.com), выбери проект (тот же, что для Firebase, или новый).
2. **IAM & Admin → Service Accounts → Create service account**.
3. Скачай JSON-ключ.
4. Положи на сервер и в `.env`:
   ```env
   GOOGLE_SHEETS_SERVICE_ACCOUNT_FILE=/home/deploy/raspisanie/api/sheets-service-account.json
   ```
   Либо inline:
   ```env
   GOOGLE_SHEETS_SERVICE_ACCOUNT_JSON={"type":"service_account",...}
   ```
5. **Не забудь включить Google Sheets API** в этом проекте: [console.cloud.google.com/apis/library/sheets.googleapis.com](https://console.cloud.google.com/apis/library/sheets.googleapis.com) → **Enable**.
6. Перезапусти `raspisanie-api`.

Если хочется переиспользовать FCM-ключ — просто не задавай `GOOGLE_SHEETS_SERVICE_ACCOUNT_*`, приложение возьмёт `FCM_SERVICE_ACCOUNT_*`. Но всё равно нужно **включить Sheets API** в том же Google-проекте.

### 4.2 Один раз на каждую таблицу: расшарить сервисному аккаунту

1. В панели зайди в **Google Таблицы** (пункт меню для tech-администратора). В шапке будет e-mail сервисного аккаунта, что-то вроде:
   ```
   raspisanie-sh44@raspisanie-sh44.iam.gserviceaccount.com
   ```
2. Открой свою Google-таблицу → **Share (Поделиться)** → введи этот e-mail, роль **Editor** (Редактор). Уведомление отправлять не нужно.

Без шаринга бэкенд не сможет читать/писать.

### 4.3 Создать привязку в панели

1. Панель → **Google Таблицы** → **+ Новая привязка**.
2. Выбери:
   - Что синхронизировать: стандартное расписание / расписание на неделю.
   - Направление: только импорт / только экспорт / в обе стороны.
   - Ссылка на таблицу (полный URL или ID).
   - Название для себя (например, «Основное расписание — 2026/2027»).
3. **Создать**.

### 4.4 Запуск

В карточке привязки — кнопки **⇣ Импортировать** и **⇡ Экспортировать**. Для расписания на неделю — сначала попросит указать понедельник нужной недели.

После запуска увидишь результат: сколько уроков, звонков, дистантных дней применено; предупреждения (если что-то не найдено или пропущено).

## 5. Как оно ведёт себя с уже существующими данными

**Импорт стандартного** — перезаписывает уроки шаблона по (день × класс). Т.е. если в таблице у 5А в понедельник только 5 уроков, а в БД было 6 — 6-й исчезнет.

**Импорт расписания на неделю** — тоже перезаписывает override-и на эту неделю у пришедших классов. Классы, которых нет в таблице (например, вы стёрли только 8-е классы), не трогаются.

**Экспорт** — заполняет только те ячейки, что описаны в формате (B8-B15, C7-S7, C8-S15). Другие ячейки листа (форматирование, шапки, доп.колонки после S) не трогает.

## 6. Автоматизация имени предмета

- При импорте, если в таблице встречен предмет, которого нет в справочнике — **предмет создаётся автоматически** (в `Subject`). Т.е. в первый раз просто прогоняешь импорт, справочник заполнится.
- Учителя и кабинеты **не забираются** из ячейки — в этой версии в ячейке живёт только название предмета. Если нужно тащить и их — скажи, добавим формат вроде `Математика · Иванова · 214`.

## 7. Что не поддерживается

- Формулы в ячейках — не читаются как формулы, читается их значение (`FORMATTED_VALUE`).
- Объединённые ячейки в областях B8-B15 / C7-S7 / C8-S15 — читаем только верхнюю-левую.
- Группы (деление на подгруппы) — при экспорте пишем только первую группу. При импорте создаётся одна группа с одним предметом.

## 8. Диагностика

- Ошибка «Sheets не сконфигурирован» — не задан `GOOGLE_SHEETS_SERVICE_ACCOUNT_*` (и нет фолбэка `FCM_SERVICE_ACCOUNT_*`).
- Ошибка «The caller does not have permission» — не расшарили таблицу сервисному аккаунту.
- Ошибка «Google Sheets API has not been used in project ...» — включи Sheets API в Google Cloud Console.
- Предупреждение «Класс «X» отсутствует в справочнике» — заведи класс через Панель → Справочники.
