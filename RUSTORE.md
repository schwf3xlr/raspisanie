## 5. Загрузить APK

1. Собери релизный APK (см. [ANDROID.md](ANDROID.md)):
   ```bash
   cd web && npm run build:android
   ```
   Дальше — в Android Studio: **Build → Generate Signed Bundle / APK → APK → release** → выбираешь `school-release.keystore`.
2. В консоли RuStore: **Файлы приложения** → **Загрузить APK**.
3. Загрузи файл `app-release.apk`. RuStore проверит:
   - подпись (наш keystore — ok),
   - `applicationId` (совпадает — ok),
   - минимальную версию Android (SDK 22+ — ok, у нас так и есть),
   - размер (<150 МБ — у нас ~10 МБ, ok).
4. Убедись, что `versionCode` уникальный (мы всегда его бампим — сейчас 7).

## 6. Как сделать скриншоты (5 штук хватит)

Формат: PNG, min 320px по короткой стороне, max 3840px. Соотношение сторон — любое, но лучше **вертикальные телефонные, 1080×2400 или ~9:19.5**.

**Что сфоткать:**

1. **Расписание на день** (главный экран ученика). Открой `/app`, выбери класс, любой рабочий день.
2. **Общая таблица** (`/all`) — вау-эффект, показывает, что можно смотреть расписание всей школы.
3. **Выбор класса** (`ClassPicker`) — красивая сетка карточек «5А, 5Б, 6А…».
4. **Учительский режим** — открой через «Я учитель», выбери любого учителя.
5. **Настройки** — свайпнутый вверх лист с темой и уведомлениями.

**Как снять:**

- **Проще всего** — на реальном телефоне: открой приложение → системный скриншот (кнопка громкость-вниз + питание) → перекинь на компьютер.
- **Из браузера** (без телефона): открой `https://school.rskbot.ru/app` в Chrome → F12 → **Toggle device toolbar** (Ctrl+Shift+M) → выбери «Pixel 7» (или свой размер) → на верхней панели `⋮` → **Capture screenshot**.
- Если хочешь эмулировать тёмную тему — Chrome DevTools → **⋮** → **More tools → Rendering → Emulate CSS media feature prefers-color-scheme: dark**.

**Совет:** сделай **2 набора** (светлая + тёмная тема) — 5 светлых + 3 тёмных = 8 скриншотов. Смотрится богаче.

## 7. Отправить на модерацию

1. **Проверить** всё в консоли: описания, ссылки, скриншоты — красный кружок «есть замечания» подсказывает, чего не хватает.
2. **Опубликовать** → приложение уйдёт на модерацию.
3. Модерация 2-7 дней. Обычно пишут комментарий, если что-то не так — на почту.

Что могут попросить:
- Уточнить назначение приложения в описании — «для учеников БОУ г. Омска СОШ № 44».
- Дополнить политику конфиденциальности пунктом про push-токены (у нас уже есть).
- Добавить контакт поддержки (у нас есть).

**После первой публикации** каждое обновление проходит модерацию **1-2 дня** (существенно быстрее).

## 8. Что поменяется у нас на сайте

- Добавим кнопку **«Скачать в RuStore»** рядом с «Скачать APK» на лендинге. Это ссылка вида `https://apps.rustore.ru/app/ru.rskbot.school44.raspisanie` — она появится после публикации.
- Приложение обновится → сможем убрать наш самописный updater (`update-check.ts`) и `latest.json` — RuStore обновляет сам. Или **оставить оба варианта** — тогда те, кто установил через APK, обновляются нашим механизмом, а через RuStore — их встроенным.

Скажешь, что тебе больше нравится — уберём или оставим.
