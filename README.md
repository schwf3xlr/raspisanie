# Расписание школы

Веб-приложение расписания уроков для БОУ г. Омска «СОШ № 44 им. А.В. Салугина».

**Стек:**
- Фронт: Vite + React + TypeScript + Tailwind + React Router
- Бэк: Node.js + Fastify + TypeScript + Prisma + PostgreSQL
- Данные: своя БД, редактируется через веб-админку (без внешних источников)

**Структура:**
```
Расписание/
├── api/          — бэкенд (Fastify + Prisma)
├── web/          — фронтенд (Vite + React)
├── *.html        — старые прототипы (можно удалить)
└── README.md
```

---

## Первый запуск

Нужен установленный **Node.js 20+**. Проверь: `node -v`.

### 1. Бэкенд

```bash
cd api
npm install
npx prisma migrate dev --name init
npm run dev
```

Бэкенд поднимется на `http://localhost:3001`. По умолчанию — демо-режим (данные встроены в код).

Чтобы подключить свою Google-таблицу, скопируй `.env.example` в `.env` и вставь `SHEET_ID`:

```
SHEET_ID=1AbCdEf...твой-id-из-URL-таблицы
```

Затем перезапусти бэкенд. При старте он синхронизирует таблицу в SQLite (`api/data/dev.db`), потом каждые 15 минут.

### 2. Фронтенд

В **новом окне терминала**:

```bash
cd web
npm install
npm run dev
```

Открой `http://localhost:5173`. Vite сам проксирует запросы к `/api/*` на бэкенд.

## Что работает

- Лендинг с описанием проекта
- Приложение расписания: выбор класса → просмотр по дням
- Тёмная / светлая / системная тема (переключается в настройках)
- «Сейчас идёт урок» с обратным отсчётом до звонка
- Группы в одном уроке (Технология Д / Технология М и т.п.)
- Кэш выбранного класса в localStorage — при повторном заходе сразу расписание

## Как обновляются данные

Бэкенд читает Google Sheets → пишет в SQLite → отдаёт по API. Синк:
- при запуске сервера;
- каждые 15 минут автоматически;
- вручную: `POST http://localhost:3001/api/sync`.

Таблица должна быть **открыта по ссылке на просмотр**. Формат — как описано в старом `README.md` прототипа (листы = дни недели, строка 7 — классы, столбец B — время, ячейки C8:S15 — уроки).
